# Single-Cycle RV32I Processor

A single-cycle RISC-V processor implementation using SystemVerilog.

## Architecture

The processor is organized into the following modules:

- ALU
- ALU Control Unit
- Control Unit
- Instruction Decoder
- Immediate Generator
- Program Counter
- Register Bank
- Single-Cycle Processor
